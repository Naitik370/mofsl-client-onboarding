# MOFSL Client Onboarding

Business MIS application for the client onboarding register described in the source DOCX.

## Run

Install and build the TypeScript frontend:

```text
python -m pip install -r requirements.txt
npm install
npm run build
npm start
```

Open `http://127.0.0.1:4173`. FastAPI serves the API and the current TypeScript frontend.

## Project structure

- `frontend/`: HTML, CSS, TypeScript, and generated browser bundle.
- `backend/`: Python server startup, HTTP router, API services, and backend tests.
- `backend/domain.py`: pure validation helpers, date/TAT calculations, masking, and onboarding constants.
- `backend/policies.py`: storage-independent role authorization policies.
- `sql/`: SQLite schema and local database.

## Included

- FastAPI JSON API with SQLite persistence.
- Normalized schema with primary keys and foreign keys across case, entry, master, holiday, settings, and audit tables.
- Denormalized report responses for the MIS frontend.
- Python-derived RFT/NRFT, query count, query hold days, working-day TAT, SLA breaches, exceptions, and stage pipeline.
- CSE, Location, and Vertical/Segment MIS views.
- TypeScript data entry and CSV upload with frontend validation.
- Append-only status history generated by the API.
- Manual process-date entry by default, with an admin-only per-entry auto-date toggle.
- Multi-user login with PBKDF2 password hashing, server-side sessions, and HttpOnly cookies.
- Role-based access for Admin, Operations, CSE, MOFSL, and Management Viewer.

Run `npm test` for backend business-rule checks and `npm run check` for TypeScript validation.
