Review management MIS

  1. Open MIS Overview

    Read Open cases, Closed cases, RFT %, Avg net TAT, SLA breaches, and Exceptions.

  2. Set the reporting period

    Choose Inward from / to dates and select Apply. Date filtering uses the earliest inward date for each Reference ID.

  3. Read the pipeline

    Use stage counts and average working-day aging to identify bottlenecks.

  4. Review Quality & Exceptions

    Rejected and cancelled cases remain visible but are excluded from final RFT and average TAT.

  5. Open Cases Requiring Attention

    Focus on open cases above the SLA or currently on hold.

Compare performance

  1. Open Performance MIS

    The active date filters continue to apply.

  2. Choose a dimension

    Select CSE, Location, or Vertical / Segment.

  3. Interpret the columns

    Compare total, open, closed, RFT, NRFT, RFT %, average net TAT, SLA breaches, and exceptions.

  4. Refresh when needed

    Select Refresh to load the latest API-calculated results.

Investigate a case

  • Search Case Register by reference, client, or masked PAN.
  • Filter the register by latest status.
  • Review entry stage, status, query count, hold days, RFT, and net TAT.
  • Open Audit History to see previous and new status, changer, owner, and notes.
  • Contact the responsible operational owner when a correction is needed.

Metric notes

  • RFT: no qualifying query event.
  • NRFT: at least one qualifying query event.
  • Net TAT: gross working days minus query hold days.
  • SLA breach: gross TAT above the configured seven working days.
  • Masked PAN: displayed like AB*****34F.

Unavailable

  • New Entry and editing.
  • Bulk Upload.
  • User Administration.
  • Full PAN access.
  • Any API write action.
