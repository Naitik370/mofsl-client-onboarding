Submit a new request

  1. Open New Entry

    Reference ID remains read-only and is generated after save. Your CSE name is filled automatically.

  2. Enter the request

    Complete Request ID, client name, PAN, account details, channel, location, segment, RM, inward date, and useful remarks.

  3. Use Request Received from CSE

    This is the normal first status. The backend assigns the next owner as Operations.

  4. Save and copy the Reference ID

    Use the generated ID to find and update the same case later.

Respond to a query or discrepancy

Always add a new event to preserve the journey.

  1. Open Case Register

    Find the assigned case and select Add update.

  2. Confirm the copied Reference ID

    The form carries forward case details and locks the stable case reference.

  3. Select the correct CSE status

    Choose the response that matches what you received or resubmitted.

  4. Add the response date and notes

    Record the resubmission date where applicable and explain the response in Query / Event Details or Remarks.

  5. Save the update

    The system creates a related row and records your authenticated display name in Audit History.

Before you save

  • The case belongs to your CSE display name.
  • You selected one of the four CSE statuses.
  • The Reference ID matches the original case for a related entry.
  • The PAN and inward date are valid.
  • Your notes clearly explain what was sent or resolved.
