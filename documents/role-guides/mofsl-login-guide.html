Update a MOFSL case

  1. Open Case Register

    Locate the Stage 5 or Stage 6 case assigned to MOFSL.

  2. Select Add update

    The form opens as a Modification and carries forward the existing Reference ID and case details.

  3. Choose the MOFSL event

    Select Query Raised, Query Resolved, Account Opened, or Communication Sent / Case Closed.

  4. Complete the event details

    A raised query requires Query / Event Details. A closed case requires account number and account opening date.

  5. Save the update

    The owner is set to MOFSL and Audit History records your authenticated display name.

Handle a MOFSL query

A query changes reportingQuery Raised by MOFSL increases Query Count, changes the case to NRFT, and begins working-day hold time. Query Resolved - Resubmitted to MOFSL ends that hold interval.
  • Explain exactly what is missing or incorrect.
  • Reuse the same Reference ID for the resolution.
  • Record resolution promptly so hold days stop accumulating.

Open and close the account

  • Confirm the PAN and client details match the submitted form.
  • Enter the account number.
  • Enter an opening date that is not earlier than the inward date.
  • Select Account Opened when opening is confirmed.
  • Use Communication Sent - Case Closed after closure communication, retaining the account details.

System safeguards

Access rulesYou can update only an existing case whose current stage is Stage 5 or Stage 6. The owner is forced to MOFSL, and only four MOFSL statuses are accepted.

Unavailable

  • Creating an original New case.
  • Bulk Upload.
  • User Administration.
  • CSE or Operations statuses.
  • Automatic date capture.
