Your daily workflow

A practical sequence for running the register.

  1. Sign in and review MIS Overview

    Check open and closed cases, RFT, net TAT, SLA breaches, exceptions, pipeline aging, and attention cases.

  2. Inspect Performance MIS

    Compare results by CSE, Location, or Vertical / Segment. Apply inward-date filters when reviewing a period.

  3. Review the Case Register

    Search by reference, client, or PAN and filter by status. Select Edit when an operational entry needs correction.

  4. Create or progress a case

    Use New Entry. New cases receive a Reference ID after save; related entries must reuse that ID.

  5. Review Audit History

    Confirm who changed a status, when it changed, the current owner, and the recorded notes.

  6. Manage users

    Open User Administration, enter a unique username and display name, choose a role, and issue a temporary password of at least eight characters.

Admin-only controls

These controls are intentionally unavailable to other roles.

Auto-capture related dateSelect the checkbox for a save when the server should fill the selected status's related blank date with today's date. A date already supplied is never overwritten.
  • User Administration: create Admin, Operations, CSE, MOFSL, or Viewer accounts.
  • Full status list: choose any Status Master value, while still following the intended six-stage sequence.
  • Bulk Upload: validate a CSV in the browser and import valid rows through the API.

Before you save

  • Request ID, client name, PAN, inward date, and latest status are complete.
  • PAN follows ABCDE1234F.
  • Query or discrepancy statuses include event details.
  • Account Opened or Case Closed includes account number and opening date.
  • The selected owner reflects who must act next.
